## Publish on GitHub Pages
1. Create a repository named `weylandx.github.io`.
2. Upload the contents of this folder to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/(root)`.
4. Save and wait for GitHub Pages to publish.

Before public release, review the experience dates and add any LinkedIn URL, CV download and project photos you want to expose.
